# home-solar-demo

ต้นแบบหน้าจอแอปพลังงานบ้าน (v2) — หน้านี้บน GitHub Pages ใช้ **ข้อมูลจำลองทั้งหมด**

- `/` แอป v2 (โมเดลบ้าน 3D, พลังงาน, การ์ดที่ชาร์จรถ EV, อุปกรณ์, ตั้งค่า)
- `/v1/` แดชบอร์ดเวอร์ชันแรก

ข้อมูลทั้งหมดผ่าน `js/data.js`:
- `SimAdapter` – ตัวจำลอง (ค่าเริ่มต้นบน github.io)
- `ApiAdapter` – Home Hub ในวง LAN บ้าน (`/api/live`, `/api/today`, `/api/day`, `/api/days`) ใช้อัตโนมัติเมื่อหน้าเว็บถูกเสิร์ฟจาก Hub
  หรือระบุ `?api=http://<hub>:8080` ; ถ้าไม่พบ API จะกลับไปใช้ตัวจำลอง · `?demo=1` บังคับโหมดจำลอง
